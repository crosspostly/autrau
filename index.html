        🔧 Как устанавливается Argos (для любопытных)
        

          Полностью автоматически. Кнопка «📥 Установить Argos» сверху делает всё сама:
          
    
            
  1. pip install argostranslate langdetect в venv сервера
    2. 
            
  2. Скачивает обе модели en↔ru (~336 МБ) с argos-net.com в фоне
    3. 
          

          

            Следи за ✓ Argos в badge над формой — когда загорится зелёным, перевод готов.
            Никаких перезапусков не нужно — пакет ставится в venv где уже работает сервер.
          

          

            Если кнопка не работает (например, нет интернета), можно вручную:

            py -3.13 -m pip install argostranslate langdetect

            py -3.13 -c "from argostranslate import package; package.update_package_index(); [p.install() for p in package.get_available_packages() if p.code in ('translate-en_ru', 'translate-ru_en')]"
